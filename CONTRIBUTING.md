# Contributing

Contributions are welcome for benchmark tasks, test cases, tooling, methodology, and independently reproduced results.

## Benchmark task requirements

A benchmark task should:

- resemble a realistic repository task
- have a precise written specification
- avoid depending mainly on memorized textbook algorithms
- include deterministic tests
- avoid external network access
- document runtime and dependency requirements
- include edge cases that distinguish shallow implementations from careful ones

Do not submit model-generated solutions inside benchmark task directories.
